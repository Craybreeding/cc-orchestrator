# Kimi Model Router

This package classifies coding and review requests before a Kimi call. It preserves native Codex/SOL ownership of tools, workspace changes, sensitive material, and high-impact actions.

The package is usable as a standalone skill directory or from `skills/kimi-model-router` in a repository. Read [SKILL.md](SKILL.md) for routing, invocation, installation, and validation instructions.

It does not configure a provider, store credentials, prove model availability, or automatically fail over between models.
